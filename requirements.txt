# =============================================================================
# Pinned, mutually-compatible environment for the nine-TSFM realized-volatility
# pipeline. All nine foundation models plus the econometric benchmarks run in
# ONE env at these versions (verified: every model package imports and the main
# run produced all nine).
#
# The binding constraints (do not relax without re-testing all models):
#   * gluonts 0.14.4 (lag-llama) requires pandas < 2.2  -> the 'Q' offset
#     deprecation in pandas 2.2 breaks it at runtime.
#   * sundial's HF remote code uses transformers DynamicCache.seen_tokens, which
#     was removed around transformers 4.46  -> need transformers < 4.46.
#   * chronos-forecasting 2.2.2 needs transformers >= 4.41.
#   => transformers must be in [4.41, 4.46); we pin 4.44.2.
#   * granite-tsfm >= 0.3.2 imports transformers symbols (check_torch_load_is_safe)
#     only present in transformers >= 4.57, and pins pandas >= 2.3.3 -> use 0.3.1.
#
# IMPORTANT: the model packages (toto-ts, granite-tsfm) carry conservative
# install pins (e.g. toto-ts pins transformers==4.52.1, pandas==2.2.3) that they
# tolerate at runtime. Install them with `pip install --no-deps`, then pin
# pandas/transformers explicitly, so they cannot drag the env to incompatible
# versions. See cluster/setup_new_models.sh. Never `pip install --upgrade` the
# foundation-model packages in this env.
# =============================================================================
